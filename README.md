# BuildQuote Pro 🏗️

Professional Quote Generator for Bahamas Construction

## Features
- ✅ Bilingual (English & Français)
- ✅ Automatic calculations
- ✅ Export PDF, Excel, CSV
- ✅ Mobile responsive
- ✅ No installation needed

## Try It Now

## How to Use
1. Fill in client information
2. Add items to the quote
3. Watch calculations update automatically
4. Export as PDF, Excel, or CSV

- Quick quote generation
